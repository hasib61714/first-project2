## About

**To-Do List App** is a clean, minimal task manager built entirely with **Vanilla JavaScript** — no frameworks, no dependencies. It demonstrates core web fundamentals: DOM manipulation, event handling, and client-side persistence through the **LocalStorage API**. Tasks survive page refreshes, filters help you focus on what matters, and the responsive layout works perfectly on both mobile and desktop.

---

## Features

- **Add Tasks** — Type a task and press Enter or click Add to instantly create a new item
- **Complete Tasks** — Click a task to toggle it as completed with a visual strikethrough
- **Delete Tasks** — Remove individual tasks with the delete button
- **Filter Views** — Switch between All, Active, and Completed task views
- **Task Counter** — Live count of remaining active tasks shown in the UI
- **LocalStorage Persistence** — All tasks are saved to the browser; data survives page refreshes
- **Responsive Design** — Fluid layout that works seamlessly on mobile and desktop
- **Clean Minimal UI** — Distraction-free interface focused on productivity

## Getting Started

### Prerequisites

Any modern web browser — no installations required.

### Installation

```bash
# Clone the repository
git clone https://github.com/hasib61714/first-project2.git
cd first-project2
```

### Usage

**Option 1 — Open directly in browser:**

```bash
# Simply open the file in any browser
open index.html       # macOS
start index.html      # Windows
xdg-open index.html   # Linux
```

**Option 2 — Use a live server (recommended for development):**

```bash
# With VS Code Live Server extension, right-click index.html
# and select "Open with Live Server"

# Or with npx
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
